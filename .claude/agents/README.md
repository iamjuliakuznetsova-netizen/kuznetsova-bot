# Агенты для монтажа видео — указатель

Пока в приложении не появилась левая панель с агентами, это твоя быстрая шпаргалка: какой агент
за какой формат отвечает и как его позвать. Позвать = просто написать в чате имя агента и дать
материал, например: «Используй агента talking-head-reels, вот видео: …».

Правило именования: имя агента = конкретный формат/тип исходника, никаких общих
«video-editor»/«montage» — чтобы по имени сразу было понятно, что это, и чтобы разные агенты не
пересекались по зоне ответственности.

| Агент | Файл | Для чего | Не для чего |
|---|---|---|---|
| `talking-head-reels` | `talking-head-reels.md` | Instagram Reels из реальной съёмки говорящей головы Юлии — субтитры, заголовки, моушен поверх видео, которое играет без изменений. Оформление берёт из `Дизайн/РОЛИКИ_ГОВОРЯЩАЯ_ГОЛОВА_ДИЗАЙНСПЕКА.md`. | Видео с нуля, карусели, любой контент без исходной съёмки |

*(сюда добавляется новая строка при каждом новом агенте)*
